# 小学校 学習内容ナビ

小学校学習指導要領（平成29年告示）をもとに、全教科等の学習内容を見られる無料Webアプリです。

**アプリを開く：** https://uramotokou-hash.github.io/gakushu-navi/

## できること

- **系統表（一枚で見る）**：教科ごとに「領域×学年」の表で、学びのつながりを一目で確認
- **学年・教科でくわしく**：学年と教科を選んで、学習内容を領域ごとに表示。キーワード検索・テキストコピーも可能
- **まとめPDF**：教科ごとに、系統表とくわしい内容を組み合わせた1枚（A4）のPDFを保存
- **解説へのリンク**：各教科の学習指導要領解説（文部科学省PDF）へ直接移動
- **標準授業時数表**（学校教育法施行規則 別表第一）

## 対象

国語・社会・算数・理科・生活・音楽・図画工作・家庭・体育・外国語活動・外国語・特別の教科 道徳・総合的な学習の時間・特別活動

## ご注意

- 内容は学習指導要領の「各学年の目標及び内容」を、教員が見通しをもつために要約・整理したものです。指導案や評価規準など正式な文書には、文部科学省の原文と解説で文言を確認してください。
- 次期学習指導要領は中央教育審議会で審議中です。告示後は内容が変わります。
- アカウント登録は不要です。入力内容はサーバーに送信されません（表示の設定のみ、お使いの端末に保存します）。
